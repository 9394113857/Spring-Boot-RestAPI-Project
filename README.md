# 🌐 Spring Boot REST API with SQLite Database  
### Fully CORS Enabled — Any Domain in the World Can Connect

This project is a fully functional **Spring Boot REST API** using **SQLite** as the database.  
All API endpoints are **globally CORS-enabled**, meaning:

✔ Any Angular / React / Vue app  
✔ Any mobile app (Android / iOS / Flutter)  
✔ Any website/domain across the world  
✔ Any backend system  

…can connect to this API **without any CORS restrictions**.

The entire application is **verified, tested, and fully working** with CRUD operations.

---

## 🚀 Tech Stack

| Layer          | Technology |
|----------------|------------|
| Language       | Java 21 |
| Framework      | Spring Boot 3.x |
| Database       | SQLite (file-based) |
| ORM            | Hibernate / Spring Data JPA |
| Build Tool     | Maven |
| API Style      | REST APIs |
| CORS           | Global, unrestricted |
| Tools Used     | cURL, VS Code |

---

## ✅ Key Features

✔ RESTful endpoints for CRUD  
✔ Lightweight SQLite DB (no server required)  
✔ Database auto-creates at runtime  
✔ Global CORS enabled → any domain allowed  
✔ Clean controller + repository architecture  
✔ Easy to integrate with Angular / React / Vue  
✔ Fully tested using cURL commands
